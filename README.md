# Quantitative-Finance
## 🗂 Project Repository

This repository contains multiple projects.  

Each project is present in its **respective branch**, and every branch includes:  
- All code used for the project  
- Datasets and Excel files required  
- Project-specific README files or documentation  
- Any other files needed during the project  

This structure ensures that each project is self-contained and can be explored independently without mixing files from other projects.
