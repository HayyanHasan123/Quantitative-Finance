# Portfolio Optimization Using Modern Portfolio Theory (MPT)

# Overview
This project applies **Modern Portfolio Theory (MPT)** to construct and analyze an **optimal investment portfolio** using historical stock data. The portfolio is built using three major US stocks: **Apple (AAPL), NVIDIA (NVDA), and Netflix (NFLX)** over the period **2020–2024**. The goal is to analyze risk–return trade-offs and identify optimal portfolio allocations.

# Objectives
- Analyze individual stock return behavior
- Measure portfolio risk and expected return
- Apply diversification principles
- Construct an efficient portfolio using MPT
- Identify optimal asset weights

# Assets Used
- Apple Inc. (AAPL)
- NVIDIA Corporation (NVDA)
- Netflix Inc. (NFLX)

# Time Period
- January 2020 to January 2025

# Data Source
- Historical stock price data from Yahoo Finance
- Adjusted closing prices used for analysis

# Technologies Used
- Python
- pandas
- numpy
- yfinance
- matplotlib
- Excel (for structured output and analysis)

# Methodology
- Download historical price data for all three stocks
- Compute daily returns
- Calculate mean returns and standard deviations
- Construct covariance and correlation matrices
- Generate portfolio returns and risks using different weight combinations
- Apply MPT principles to analyze diversification benefits

# Key Financial Concepts Used
- Expected Return
- Portfolio Variance and Standard Deviation
- Covariance and Correlation
- Risk–Return Tradeoff
- Diversification
- Efficient Portfolio Construction

# Portfolio Analysis
- Individual stock risk and return comparison
- Combined portfolio risk reduction through diversification
- Weight-based return and volatility estimation
- Comparison of different portfolio allocations

# Results and Insights
- Diversification reduces overall portfolio risk
- NVDA shows higher volatility and return potential
- AAPL provides relative stability
- NFLX contributes diversification benefits
- Optimal portfolio balances high-growth and stable assets
